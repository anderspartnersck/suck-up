# SUCK UP — playable web build

A Castle Killscreen arcade title by Anders & Partners LLC. A 1–2 player
competitive UFO-abduction game set on a scrolling night farm near Towson, MD.

**Play:** open `index.html` (this repo is deployed via GitHub Pages).

- Mouse edition (this build): fly to the cursor, click to fire the beam.
- Keyboard: WASD + Z/X (P1) · IJKL + M/, (P2).

Self-contained static site — HTML5 canvas + assets, no build step, no server
needed. Generated from the master in the private Castle Killscreen tree; edit
there, not here.
